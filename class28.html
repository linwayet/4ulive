02 — TYPOGRAPHY

三種字，各司其職

Fraunces 是雜誌標題，帶古典義式手感；Noto Sans TC 是中文內文，乾淨可讀；JetBrains Mono 是數據與標籤，給課程一點實驗室的感覺。

Display · 標題
Fraunces
Heart.
心 — 一顆會跳的肌肉

用於大標、章節標題、單字英文。粗體 900 給標題，斜體 italic 400 給副標與英文片語。letter-spacing 收緊 -.03em。中文與英文混排時，英文常用斜體製造節奏感。

Body · 內文
Noto Sans TC
心肌細胞不會疲勞。
這個句子描述了心臟最神奇的特性之一。每一顆細胞、每一次收縮、每一個動作電位，都在不知疲倦地工作著，從你出生到死亡，從未停止。

中文內文 16px / line-height 1.75。400 與 500 兩個字重交替使用，500 用於需要強調的小段落或關鍵字。

Mono · 數據
JetBrains Mono
HR: 72 bpm
CO = HR × SV
DAY · 01 / 30

用於：所有數據、公式、ECG 標籤、課程編號、tag、IPA 音標、單位、時間戳記。letter-spacing 加寬 .15em–.3em 給金屬冷感。

Hierarchy · 層級
H1 · 64–128px
H2 · 36–64px
H3 · 20–24px
Body · 14–16px / 1.75
Caption · 11–13px

六層字級。任何一頁課程最多用四層，避免雜亂。

04 — PAGE STRUCTURE

一堂課的七個區塊

每一天的 HTML 頁面都遵循這個結構。不是每一頁都會用到全部七個，但順序固定，讓讀者建立節奏感。

引言 Hero
The Opening Question

大標 + 一個讓人想往下看的問題。例如：「為什麼心臟不會累？」附當日核心 SVG 圖示（跳動心臟、神經訊號、血管網等）。

核心概念 Core
The Big Idea

用白話講清楚一個關鍵概念。配 1 張對比圖或類比（例：心肌 vs 骨骼肌、馬達 vs 引擎）。成人科普版，盡量用生活比喻。

互動解剖 Interactive
Click to Explore

SVG 結構圖。讀者點擊各部位（細胞膜、心房、瓣膜、神經節）會跳出中英解說。輕量但能讓抽象概念落地。

三大重點 Highlights
Three Things to Remember

三張並列卡片，每張一個記憶錨點。卡片用 Honey/Amber/Sun 三色區隔。降低資訊負擔，幫助記憶。

動畫示範 Animation
See It Move

CSS 或 SVG 動畫示範一個動態過程（離子流動、瓣膜開合、血流方向）。可暫停、可重播。

核心詞彙 Glossary
Key Vocabulary

8–12 個當日關鍵詞，英中對照，附 IPA 音標與一句話定義。網格排列，hover 變色。

自測 Quiz
Check Yourself

3 道題。點擊作答，立即顯示中英解說。正確會有溫和的 confetti，答錯不扣分、給解釋。

尾聲 Outro
Tomorrow Preview

一句話總結今天 + 預告明天。底部固定有 Day 編號與課程導航條。

06 — PRINCIPLES

六條不變的原則

無論是哪一天的課程，這六條原則都不動搖。

— 01
中英並列，永遠

所有專有名詞都用「中文（English）」格式呈現。標題的英文用 Fraunces 斜體，視覺與中文錯落形成節奏。

— 02
先比喻，再術語

這是成人科普課程，不是醫學院教科書。每一個專業名詞，先給生活比喻（馬達、水管、電線），再解釋學理。

— 03
一頁，一主題

每天一個核心概念。寧可少不貪多。資訊密度高，但結構清晰；讀完一頁，腦中只需留下一個畫面。

— 04
互動是工具，不是裝飾

點擊、tooltip、動畫，都必須服務理解。漂亮但無意義的動效一律捨棄。能用 CSS 不用 JS。

— 05
暖色，但不甜膩

夕陽橘紅是基調，但要靠 ink 深褐與 dusk 暮色拉住對比。避免粉橘、淡黃這種「兒童感」配色。

— 06
記得心臟還在跳

每頁右下角都有一顆小心臟在跳，提醒讀者：你現在學的東西，正在你體內運作。
