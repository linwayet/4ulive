UniProt：確認蛋白質身份與功能

搜尋 "TP53 human" 或直接輸入 AC 號碼 P04637。確認 Swiss-Prot（人工審核）或 TrEMBL（自動）、查看功能描述、GO 標注（分子功能/生物過程/細胞定位）、已知 PTM（磷酸化位點）和疾病關聯。

🌐 https://www.uniprot.org/uniprotkb/P04637
2

UniProt：下載 FASTA 序列 / 查看域結構

點擊「Sequences」下載 FASTA 格式，或在「Features」頁查看結構域（TAD、DBD、OD、CTD）、信號肽、跨膜區和已知功能性殘基的位置。

下載：Download → Format: FASTA → Go
3

PDB：找到最佳代表結構

從 UniProt 頁面的「Structure」欄直接點入，或在 RCSB.org 搜尋 "P04637"。篩選條件：分辨率 ≤ 2.5 Å、R-factor、是否有配體/藥物。p53 DBD + DNA 複合體（2OCJ, 2.05 Å）是教學標準結構。

🌐 https://www.rcsb.org/search?query=P04637
4

PDB：3D 可視化與配體分析

使用 RCSB 內建的 Mol* 或 NGL Viewer 查看 3D 結構。切換「表面 Surface」模式看疏水口袋、「電荷 Electrostatics」模式看 DNA 結合面。下載 mmCIF 或 PDB 格式用於本地分析。

View → 3D View → Mol* → Surface → Hydrophobicity
5

HPA：查詢組織和細胞定位

在 proteinatlas.org 搜尋 "TP53"。查看「Tissue Atlas」（40 種正常組織的免疫組化染色圖）、「Cell Atlas」（單細胞水平的亞細胞定位）和「Pathology Atlas」（癌症預後與生存曲線）。

🌐 https://www.proteinatlas.org/ENSG00000141510-TP53

圖書館比喻

UniProt 是圖書館的館藏目錄（你查的書叫什麼、由誰寫、內容是什麼）； PDB 是實體書本（你可以翻開看每頁、每行的字）； HPA 是讀者報告（這本書在哪些城市最流行、在哪些人群中最暢銷、讀完有什麼效果）。 三本工具書缺一不可。

SP

Swiss-Prot vs TrEMBL：先選 Swiss-Prot！

搜尋結果中優先選「Reviewed · Swiss-Prot」（金色標誌）——由生物學家人工核對，準確性最高。TrEMBL 是電腦自動注解，數量多但錯誤率也高，適合找罕見物種蛋白。

GO

GO 本體論三大分類

分子功能（MF, Molecular Function）、生物過程（BP, Biological Process）、細胞組成（CC, Cellular Component）。GO 標注有「實驗證據（EXP）」和「計算預測（IEA）」之分，研究時優先看有實驗證據的。

PDB 蛋白質資料庫深度導覽

Protein Data Bank（RCSB PDB）是全球最大的生物大分子三維結構儲存庫， 1971 年成立，現有 220,000+ 個結構。每個 PDB 條目存放原子的精確 3D 座標（x, y, z）， 是現代結構生物學和藥物設計的基石。

PDB 關鍵資訊說明評估標準
Resolution 結構解析度（Å）。越小越清晰：1.0-1.5 Å 原子級，2.0-2.5 Å 可靠，3.0 Å+ 需謹慎 選 ≤ 2.5 Å 作為研究用結構
R-factor / Rfree 結構模型和原始繞射數據的擬合程度。R < 0.25, Rfree < 0.30 為可接受 Rfree - R < 0.05 為良好，差距大表示過擬合
Method X-ray（主流）、Cryo-EM（大複合體）、NMR（溶液狀態、小蛋白）、Neutron Cryo-EM 現已可達 1.5 Å 分辨率

B-factor 溫度因子，反映原子位置的不確定性/靈活性。高 B-factor 表示該區域柔性大 活性位的高 B-factor 可能影響藥物結合
Biological Assembly 晶體中的不對稱單元（asymmetric unit）可能只是生物功能體的一部分（如四聚體） 用「Biological Assembly」頁查看真正的功能性多聚體
🏛️

建築藍圖比喻

PDB 就像一棟建築的精密藍圖——每個原子的位置精確到 Å（0.1 nm）等級。 分辨率是「藍圖的比例尺」：1 Å 能看到每顆石頭的紋路，3 Å 只能看到牆壁的輪廓。 B-factor 是「工程公差」：B 值高的地方是「施工時晃動太多」的柔性部位，藥物很難精確嵌合。

KM

Kaplan-Meier 生存曲線分析

HPA Pathology Atlas 提供各癌症中高/低表達該蛋白的患者生存率比較（log-rank test）。 這是判斷「蛋白質是否為癌症預後生物標誌物」的最快方法，無需自己跑統計。 例：TP53 高表達在結直腸癌中與較差預後相關（unfavorable）。

IHC

免疫組化圖片判讀

棕色（DAB 染色）= 蛋白質陽性，藍色（蘇木精）= 細胞核背景染色。 染色強度分 High / Medium / Low / Not detected。 注意：HPA 的抗體可能對某些蛋白不夠特異，要配合「Antibody Validation」評分（Enhanced Validation 最可靠）。

PART 06

三庫串聯實戰技巧

掌握這些技巧，讓三個資料庫的查詢效率提升 10 倍。

UniProt
用 AC 號碼，不要用蛋白質名
同一個蛋白可能有 10+ 個別名（p53 = TP53 = TRP53 = Li-Fraumeni...）。一旦確認 UniProt AC（如 P04637），用它當「通用護照」查詢所有資料庫，永遠指向同一個蛋白。
PDB
同一蛋白有 400+ 結構怎麼選？
篩選策略：① 分辨率最高（≤ 2.0 Å）；② 有配體/藥物的優先（針對藥物對接）；③ 選擇含完整功能域的結構；④ 引用量最高的通常是「社群標準結構」。PDB 的 "Representative Structure" 功能自動選最佳。
HPA
Enhanced Validation 抗體優先
HPA 每個蛋白可能有多隻抗體，驗證等級不同。選「Enhanced Validation」（綠色盾牌）的抗體結果最可靠，有 WB / IF / IHC 多平台一致驗證，適合實驗設計參考。
AlphaFold
找不到 PDB 結構？用 AlphaFold DB
若蛋白沒有實驗結構，UniProt 頁面會直接嵌入 AlphaFold 預測結構（alphafold.ebi.ac.uk，涵蓋 200M+ 蛋白）。pLDDT 分數 > 90 = 高置信度，可作為後續分析的基礎。
批量查詢
ID Mapping：一鍵跨庫轉換
UniProt 的 ID Mapping 工具（uniprot.org/id-mapping）可一次輸入 100+ 個基因名或 Ensembl ID，自動輸出 UniProt AC、PDB ID、RefSeq、Ensembl 等所有對應 ID，是多蛋白研究的必備工具。
可視化
免費 3D 可視化工具選擇
線上：RCSB Mol*（最新）；離線：PyMOL（最強，需授權）、ChimeraX（免費，Cryo-EM 首選）、UCSF Chimera（老牌）。初學者從 RCSB 內建 Mol* 開始，進階用 PyMOL 做高品質論文圖。

def get_uniprot(ac):
  url = f"https://rest.uniprot.org/uniprotkb/{ac}.json"
  data = requests.get(url).json()
  # 提取 PDB ID 列表
  pdb_ids = [ref['id'] for ref in data.get('uniProtKBCrossReferences',[])
            if ref['database'] == 'PDB']
  return data, pdb_ids

# ② PDB：取得最高分辨率結構資訊
def get_best_pdb(pdb_ids):
  url = f"https://data.rcsb.org/rest/v1/core/entry/{pdb_ids[0]}"
  return requests.get(url).json()

# ③ HPA：透過 Ensembl ID 查詢表現數據
# （HPA 無公開 REST API，建議直接訪問頁面或下載 TSV 檔案）

完整術語字典

蛋白質資料庫與查詢術語｜中英對照｜點擊展開

📋 UniProt 術語
AC Accession Number（登錄號）UniProt Accession 識別碼▶

UniProt 給每個蛋白質條目的唯一永久識別碼，格式如 P04637（p53）。AC 永遠不變，即使蛋白質名稱被修改。查詢蛋白質時永遠用 AC，不要用名稱，避免名稱混亂問題。Swiss-Prot 條目以 P/Q/O 開頭；TrEMBL 條目以字母+數字組合。

Swiss-Prot 格式：[A-N,R-Z][0-9][A-Z][A-Z,0-9][A-Z,0-9][0-9] | TrEMBL：[O,P,Q][0-9][A-Z,0-9]{4}[0-9]

AC 就像身份證號——名字可以改（蛋白質重新命名），身份證號永遠不變。

SP Swiss-Prot（人工審核資料庫）UniProtKB/Swiss-Prot 資料品質▶

UniProt 中人工審核的高品質子資料庫，約 570,000 條目（截至 2024）。每條由生物學家手動核查文獻、整合功能注解、確認序列正確性。搜尋時選「Reviewed」過濾出 Swiss-Prot 條目。

Swiss-Prot 條目標識：「Reviewed · UniProtKB」金色標誌 | Entry status: Reviewed

Swiss-Prot 是「精校版百科」，TrEMBL 是「機器初稿」——前者慢但準，後者多但有錯。研究用前者，搜尋新蛋白才考慮後者。

GO 基因本體論Gene Ontology 功能標注▶

標準化的生物學詞彙系統，描述基因/蛋白質的分子功能（MF）、生物過程（BP）和細胞組成（CC）。每個 GO term 有唯一 ID（如 GO:0003677 = DNA binding）。GO 標注有「實驗證據代碼（EXP, IMP, IDA）」和「計算推論（IEA, ISS）」之分。

MF：molecular function（做什麼）| BP：biological process（參與什麼）| CC：cellular component（在哪裡）

GO 本體論就像圖書館的分類系統——不管你管它叫「氧化還原酶」還是「去氫酶」，GO 給它一個統一編號 GO:0016491，全球研究者都能比對。

PTM 翻譯後修飾Post-Translational Modification 修飾▶

蛋白質合成後在特定胺基酸殘基上發生的化學修飾，改變蛋白質的活性、定位、穩定性和交互作用。UniProt 在 PTM/Processing 頁面列出已知修飾的精確位置（殘基序號）和類型。

常見 PTM：磷酸化(P)·泛素化(Ub)·乙醯化(Ac)·甲基化(Me)·糖基化(Gly)·SUMO 化

PTM 就像給蛋白質「換裝」或「貼標籤」——同一條蛋白質鏈，磷酸化後可能從「沉睡」變「激活」，泛素化後就被送去垃圾桶（蛋白酶體）。

Iso 異構體 / 剪接變體Isoform / Splice Variant 序列▶

同一個基因透過選擇性剪接（alternative splicing）產生的不同 mRNA 和蛋白質形式。UniProt 的 Canonical sequence 是主要形式，其他 isoform 以序列差異標示。p53 有 9 種 isoform（α, β, γ, δ...），不同 isoform 有不同功能。

Isoform ID 格式：P04637-1（canonical）, P04637-2, P04637-3...
🔬 PDB 結構術語
PDB ID PDB 四字元識別碼PDB Entry Identifier 識別碼▶

每個 PDB 結構條目的 4 字元識別碼，格式為數字 + 字母（如 2OCJ = p53 DBD-DNA 複合體）。2024 年後新格式升為 8 字元（如 1ABC1234）以容納更多條目。透過 PDB ID 可直接訪問任何結構：rcsb.org/structure/2OCJ。

舊格式（4字元）：[0-9][A-Z,0-9]{3} | 新格式（8字元）：[0-9][A-Z,0-9]{7}

PDB ID 就像結構的「身份證」——全球所有研究者引用相同結構時用這個碼，確保討論的是同一個結晶實驗結果。

Å 埃格斯特倫（解析度單位）Ångström — Resolution Unit 解析度▶

1 Å = 0.1 nm = 10⁻¹⁰ m。PDB 結構的解析度以 Å 表示，數字越小越清晰：≤ 1.5 Å 可見氫原子位置（原子級），2.0 Å 可靠（適合大多數研究），2.5-3.0 Å 可見主鏈走向，>3.5 Å 只能確定整體折疊。

C-C 鍵長 ≈ 1.54 Å | C-N 鍵長 ≈ 1.47 Å | 氫鍵長度 ≈ 2.8-3.0 Å

解析度就像相機像素——1 Å 結構是 4K 超清，能看清每個原子的「臉」；3 Å 結構是標清，能認出蛋白質的「輪廓」但模糊。

cryo 冷凍電子顯微鏡Cryo-EM · Cryo-Electron Microscopy 實驗方法▶

2017 年諾貝爾化學獎得主技術（Jacques Dubochet, Joachim Frank, Richard Henderson）。將蛋白質在液氮中快速冷凍、保留天然構象，用電子束成像。優點：無需結晶，適合大複合體（核糖體、蛋白酶體）；缺點：解析度曾不如 X-ray，但現已可達 1.2 Å。

Cryo-EM 流程：純化蛋白 → 玻璃化冷凍 → TEM 成像 → 顆粒挑選 → 3D 重建（CTF 校正）

Cryo-EM 就像「分子冰雕攝影」——把蛋白質瞬間冷凍在接近原生的水溶液狀態，拍下無數個方向的投影，電腦再重建出 3D 像。

B-fac B 因子（溫度因子）B-factor · Temperature Factor 結構品質▶

PDB 結構中每個原子的「位置不確定性」指標。B 因子高 = 該原子在晶體中位置變化大（柔性/無序）。通常以彩色管狀圖呈現（藍=低B，紅=高B）。蛋白質活性位的 B 因子分析是預測蛋白質-配體結合口袋柔性的重要指標。

B = 8π²<u²>（u² = 原子均方位移）| 典型值：5-20 Å² 為剛性，>50 Å² 為高度柔性

B 因子就像照片的「動態模糊」——低 B 因子（清晰）代表原子幾乎不動，高 B 因子（模糊）代表這個位置的原子在跳舞，你沒法精確定位它。

AF2 AlphaFold 2 結構預測AlphaFold 2 · DeepMind AI 結構▶

DeepMind 2021 年發布的 AI 蛋白質結構預測系統，2024 諾貝爾化學獎。預測超過 2 億個蛋白質結構（幾乎覆蓋所有已知序列的蛋白）。UniProt 頁面直接內嵌 AlphaFold 預測結構。pLDDT 分數（0-100）評估預測可信度：>90 高置信，50-70 低置信（常為無序區域）。

pLDDT 顏色碼：深藍（>90 高置信）→ 淺藍（70-90）→ 黃色（50-70）→ 橙色（<50 低置信/無序）

AlphaFold 是「蛋白質的 Google Maps 衛星圖」——對於沒有實驗結構的蛋白，AlphaFold 提供第一張「預測地圖」。準確度很高（主鏈），但配體結合口袋和柔性區域仍需實驗驗證。

🔭 HPA 術語
IHC 免疫組化Immunohistochemistry 實驗技術▶

用特異性抗體在組織切片上偵測目標蛋白的技術。棕色（HRP-DAB）= 陽性；藍色（蘇木精）= 核背景。HPA 的 Tissue Atlas 使用 IHC，對每個蛋白在 40 種組織的染色圖片進行人工評分（Not detected / Low / Medium / High）。

IHC 流程：組織固定（FFPE）→ 抗原修復 → 一抗（目標蛋白）→ 二抗（HRP 標記）→ DAB 顯色 → 蘇木精複染

IHC 就像給組織切片「染指紋粉」——只有表達目標蛋白的細胞才會染成棕色，讓你一眼看出蛋白在哪個組織、哪種細胞類型高表達。

KM Kaplan-Meier 生存曲線Kaplan-Meier Survival Analysis 臨床統計▶

比較「高/低蛋白質表現」兩組癌症患者存活率的統計方法。HPA Pathology Atlas 對 17 種癌症提供 KM 曲線，並以 log-rank test 計算 p 值。Favorable（高表達 = 長存活）= 腫瘤抑制蛋白；Unfavorable（高表達 = 短存活）= 癌症驅動蛋白。

HPA 預後分類：Favorable / Unfavorable / Not significant | p < 0.05 = 統計顯著

KM 曲線就像「患者命運圖」——兩條線（高低表達組）分得越開，說明這個蛋白的預後預測力越強。可以在 5 分鐘內判斷一個蛋白是否值得作為癌症生物標誌物。

UMAP 單細胞資料降維圖Uniform Manifold Approximation 單細胞▶

HPA Single Cell Atlas 使用 UMAP 降維圖展示單細胞 RNA-seq 數據。每個點是一個細胞，顏色代表基因表現量。可以看出目標蛋白在哪種細胞亞群（T 細胞 vs B 細胞 vs 腫瘤細胞）中高表達，比傳統 bulk RNA-seq 更精細。

UMAP 顏色碼：深紅 = 高表現 → 灰色 = 不表現 | 每個群集 = 一種細胞類型
⚡ 通用概念 General Concepts
FASTA 序列格式FASTA Sequence Format 格式▶

最通用的序列文字格式，以 ">" 開頭的描述行 + 序列行組成。可用於蛋白質（胺基酸單字母碼）或核酸（ATCG）。BLAST 序列比對、多序列比對（CLUSTAL, MUSCLE）、系統發生樹分析的起點都需要 FASTA 格式。

>sp|P04637|P53_HUMAN Cellular tumor antigen p53 OS=Homo sapiens
MEEPQSDPSVEPPLSQETFSDLWKLLPENNVLSPLPSQAMDDLMLSPDDIEQWFTEDP

FASTA 是序列的「文字版食譜」——一行描述（">" 開頭），然後是胺基酸組成，全球所有序列分析軟體都能讀懂。

BLAST 基本局部比對搜索工具Basic Local Alignment Search Tool 序列比對▶

NCBI 的序列相似性搜索工具，在 2 億+ 序列資料庫中找出與查詢序列相似的條目。E-value（期望值）= 随機比對到這種相似程度的概率；E < 0.001 為顯著。UniProt 頁面提供直接的 BLAST 搜索按鈕。

BLASTP（蛋白→蛋白）| BLASTX（核酸→蛋白）| tBLASTn（蛋白→核酸）
Identity > 30% = 同源蛋白 | E-value < e-10 = 高度顯著

BLAST 是序列世界的「Google 圖片搜索」——你上傳一張圖（序列），它找出資料庫中所有視覺上相似的圖（同源序列），按相似度排名輸出。

IDM ID Mapping（跨庫 ID 轉換）Identifier Mapping 工具▶

UniProt ID Mapping 工具可一次批量轉換基因名、Ensembl ID、RefSeq、PDB ID、NCBI Gene ID 等不同資料庫的識別碼，是多蛋白研究（如蛋白質組學）的關鍵工具。支援最多 100,000 個 ID 批量轉換。

https://www.uniprot.org/id-mapping
輸入：gene names / Ensembl IDs → 輸出：UniProt AC + PDB + RefSeq + ...

ID Mapping 就像「翻譯字典」——TP53（HGNC 名）= P04637（UniProt）= ENSG00000141510（Ensembl）= 7157（Entrez Gene）= 2OCJ（代表 PDB），全都是同一個蛋白的不同「語言」。

mmCIF 大分子晶體學資訊框架macromolecular Crystallographic Information File 檔案格式▶

PDB 官方推薦的現代結構格式，取代舊的 .pdb 格式（有 99,999 原子數量上限）。mmCIF（.cif）格式支援超大結構（如核糖體、病毒衣殼），包含更豐富的元數據和驗證報告。PyMOL、ChimeraX、Mol* 都支援 mmCIF。

下載：rcsb.org/structure/2OCJ → Download Files → mmCIF Format
