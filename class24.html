按系統分類，中英對照，含記憶提示

🧩 如何使用詞彙表？

遇到陌生詞先看詞根：-ology 表示「學科」，-itis 表示「發炎」，osteo- 表示「骨骼」——懂詞根，自然讀得懂！

方向與位置術語
Anatomical Directions · 14 詞
Anterior / Posterior前 / 後腹側為前（anterior），背側為後（posterior）
Superior / Inferior上 / 下靠頭為上，靠腳為下
Medial / Lateral內側 / 外側靠身體中線為 medial
Proximal / Distal近端 / 遠端四肢用語：靠軀幹為近端
Superficial / Deep淺層 / 深層距體表遠近的相對位置
Ipsilateral / Contralateral同側 / 對側神經學常用術語
Sagittal plane矢狀面將身體分為左右兩半的切面
Coronal / Frontal plane冠狀面將身體分為前後兩半
Transverse / Axial plane橫切面CT 掃描最常用的角度
Ventral / Dorsal腹側 / 背側多用於脊椎動物比較解剖
Cranial / Caudal頭側 / 尾側cranium = 頭顱，cauda = 尾巴
Prone / Supine俯臥 / 仰臥手術姿勢術語
Flexion / Extension屈曲 / 伸展關節角度減小/增大的動作
Abduction / Adduction外展 / 內收遠離/靠近身體中線的動作

骨骼系統關鍵詞
Skeletal System · 16 詞
Cranium頭顱骨crani- 來自希臘語「頭」
Vertebra (pl. vertebrae)脊椎骨cervical / thoracic / lumbar / sacral
Sternum胸骨位於胸部正中，共三節
Clavicle鎖骨最常骨折的骨骼之一
Scapula肩胛骨三角形，俗稱「翅膀骨」
Humerus / Radius / Ulna肱骨 / 橈骨 / 尺骨上臂一根 + 前臂兩根
Carpals / Metacarpals / Phalanges腕骨 / 掌骨 / 指骨手部三段骨骼結構
Pelvis / Ilium / Ischium / Pubis骨盆 / 髂骨 / 坐骨 / 恥骨骨盆由三塊骨融合而成
Femur股骨（大腿骨）人體最長、最強壯的骨骼
Patella髕骨（膝蓋骨）種子骨（sesamoid bone）的最大代表
Tibia / Fibula脛骨 / 腓骨小腿兩根骨，tibia 較粗

Bone marrow骨髓紅骨髓造血，黃骨髓儲存脂肪
Synovial joint滑液關節有關節腔、滑液的活動性關節

肌肉系統關鍵詞
Muscular System · 14 詞
Skeletal muscle骨骼肌（橫紋肌）有意識控制，附著於骨骼
Cardiac muscle心肌不受意識控制，有閏盤
Smooth muscle平滑肌內臟、血管壁，無橫紋
Origin / Insertion起端 / 止端origin 固定不動，insertion 跟著移動
Agonist / Antagonist主動肌 / 拮抗肌二頭肌收縮時，三頭肌為拮抗肌
Biceps brachii肱二頭肌bicep = 兩頭，brachii = 手臂的
Triceps brachii肱三頭肌伸展手肘的主要肌肉
Deltoid三角肌希臘字母 Δ（Delta）形狀
Quadriceps / Hamstrings股四頭肌 / 股後肌群大腿前後的主要肌群
Gastrocnemius腓腸肌（小腿肚）gastro = 肚子；跑步主力肌
Diaphragm橫膈呼吸最重要的肌肉
Rectus abdominis腹直肌俗稱「六塊腹肌」
Rotator cuff旋轉肌袖穩定肩關節的4條肌肉
Tendon / Ligament肌腱 / 韌帶腱連接肌肉與骨骼，韌帶連接骨與骨

Frontal / Parietal / Temporal / Occipital lobe額 / 頂 / 顳 / 枕葉大腦的四大分葉
Meninges腦脊膜硬腦膜 / 蜘蛛膜 / 軟腦膜（三層）
CSF (Cerebrospinal fluid)腦脊液緩衝保護大腦的液體

Dermatome皮節每條脊神經支配的皮膚區域
Gray matter / White matter灰質 / 白質灰質含神經元體；白質含有髓鞘軸突

Cardio & Respiratory · 14 詞
Atrium / Ventricle心房 / 心室上方兩個心房，下方兩個心室
