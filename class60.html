戰略大轉向：從「投資別人」到「自己上場」

Microsoft draws a line: its own models, agents, and intelligence layer

  • For years, Microsoft's AI empire was built on other people's models — billions into OpenAI, plus backing Anthropic.
  • At Build 2026 (San Francisco), Microsoft unveiled seven in-house AI models, a new agent stack, the always-on agent Scout, the Microsoft IQ intelligence layer, an AI security system, and the Majorana 2 quantum chip.
  • Satya Nadella: every company should move from merely consuming a frontier model to fully participating at the frontier.
  • Economics matter: with its own models on Azure, Microsoft controls the whole stack → lower costs, better margins.
繁中摘要
多年來微軟的 AI 版圖都建立在別人的模型上（重金投資 OpenAI、也投資 Anthropic）。但在 2026 年 Build 大會上，微軟一口氣發表七個自研模型、Scout 常駐代理人、Microsoft IQ 智慧層與 Majorana 2 量子晶片，正式宣告「畫清界線」。納德拉直言：企業不能只當前沿模型的消費者，要親自參與前沿。背後的盤算很實際——自家模型跑在 Azure 上，整條技術棧自己掌控，成本更低、利潤更高。
2

旗艦模型 MAI Thinking 1：從零訓練的推理模型

First reasoning model trained from scratch on clean, licensed data

  • Trained on commercially-licensed data, with no distillation from third-party systems — avoiding legal and dependency risks.
  • A mid-sized reasoning model with 35 billion active parameters; context window reported as 256K tokens (some coverage says 128K).
  • Mustafa Suleyman (CEO of Microsoft AI): after tuning for McKinsey, it outperformed GPT-5.5 on quality with roughly 10× better cost efficiency (based on public pricing, scaled across model sizes).
繁中摘要
主打模型 MAI Thinking 1 是微軟第一個「從零訓練」的推理模型，強調只用合法商業授權資料、完全不蒸餾第三方模型——這在當前的訓練資料與抄襲爭議下是關鍵賣點。它是 350 億活躍參數的中型推理模型（上下文視窗 25.6 萬或 12.8 萬 token，說法不一）。微軟 AI 執行長蘇萊曼宣稱：替麥肯錫調校後，品質贏過 OpenAI 的 GPT-5.5，成本效率還高出約十倍。這等於是說：我能打贏我投資的公司，而且更便宜。
3

MAI Code 1 系列：直攻開發者工具

Coding models shipped straight into GitHub, Copilot, and VS Code

  • MAI Code 1 Flash converts text descriptions into source code for apps and websites.
  • Rolling out across GitHub, Copilot, and VS Code — not an isolated lab release, but tools millions already use.
  • Microsoft claims MAI Thinking 1 was preferred over Claude Sonnet 4.6 in blind evaluations by Surge (independent human raters), and matches Claude Opus 4.6 on coding benchmarks like SWE-Bench Pro.
  • Available in private preview on Microsoft AI Foundry; a Flash version targets speed and cost.
繁中摘要
程式碼模型 MAI Code 1 Flash 能把文字描述直接變成 App 或網站程式碼，而且不是關在實驗室裡，而是直接部署到 GitHub、Copilot 和 VS Code——數百萬開發者天天在用的工具。微軟還宣稱在獨立評測機構 Surge 的盲測中，MAI Thinking 1 比 Claude Sonnet 4.6 更受偏好，並在 SWE-Bench Pro 等程式benchmark上追平 Claude Opus 4.6。策略很熟悉：一個強推理模型扛重活，Flash 快速版顧成本與速度。（注意：這些是微軟單方面的宣稱。）

多模態全家桶：影像、語音、轉錄

Image, voice, and transcription round out the seven-model family

  • MAI Image 2.5 (+ Flash variant): text-to-image and image-to-image; already live in PowerPoint, rolling out on OneDrive.
  • MAI Transcribe 1.5: high-accuracy transcription across 43 languages; streaming coming soon.
  • MAI Voice 2 (+ Flash): available in 15+ additional languages; can produce new voice options.
  • Together: a full model layer for office work, coding, voice, images, transcription, reasoning, and agents.
繁中摘要
七模型家族不只文字與程式碼：MAI Image 2.5 支援文生圖與圖生圖，已上線 PowerPoint、即將進駐 OneDrive；MAI Transcribe 1.5 提供 43 種語言的高準確度轉錄（串流版即將推出）；MAI Voice 2 新增 15 種以上語言並能生成新語音。拼起來看，微軟正在打造一個涵蓋辦公、開發、語音、影像、轉錄、推理與代理人的完整 AI 模型層。
5

Microsoft IQ：讓 AI 真正「懂你的公司」

A unified intelligence layer: Work IQ, Fabric IQ, Foundry IQ, Web IQ

  • Goal: move agents away from generic chatbot behavior toward business context and grounding → fewer hallucinations.
  • Work IQ: understands people, emails, documents, meetings, and their relationships in Microsoft 365 (APIs available June 16).
  • Fabric IQ: a semantic foundation (like an ontology) for structured business data on Microsoft Fabric.
  • Foundry IQ: handles unstructured info — wikis, policies, contracts, the live web.
  • Web IQ: model-agnostic, native to MCP; Microsoft claims it returns relevant information blocks ~2.5× faster than the next best alternative.
繁中摘要
Microsoft IQ 是統一的「智慧層」，目的是讓 Copilot 和代理人不再只是泛用聊天機器人，而是真正理解所在組織的脈絡，降低幻覺。它有四個成員：Work IQ 掌握 M365 裡的人、信件、文件、會議及其關聯（API 於 6 月 16 日開放）；Fabric IQ 替結構化商業資料建立語意基礎（類似本體論）；Foundry IQ 處理 wiki、政策、合約等非結構化文件；新成員 Web IQ 提供網路即時資訊，原生支援 MCP 協定，微軟宣稱速度比次佳方案快約 2.5 倍。模型、工作脈絡、商業資料、文件檢索、網路接地——微軟正在從各個角度把這套堆疊蓋起來。
6

Scout：第一個「Autopilot」常駐代理人

An always-on agent with its own governed identity

  • A new category: autopilots — agents that stay active in the background, work autonomously, and act on your behalf under set permissions.
  • Each agent has its own governed Entra identity: actions are traceable; credentials are task-scoped, end-to-end protected, redacted from logs.
  • Integrated across Teams, Outlook, OneDrive, SharePoint; connects to email, calendar, contacts, documents, browser, desktop, and MCP servers.
  • Use cases: scheduling across time zones, prep materials, blocking calendar time, spotting stalled decisions before they become blockers.
  • Built on OpenClaw (open-source, appeared Nov 2025); Microsoft contributes policy conformance upstream. Sensitive actions can require human sign-off; Purview policies (sensitivity labels, DLP) are enforced.
  • Now in private preview for select customers and Frontier organizations.
繁中摘要
Scout 是微軟首個「Autopilot」級代理人：一直在背景運作、自主工作、代表你行事。關鍵設計是「自有身分」——每個代理人都有受治理的 Entra 身分，做的每件事都可追溯到公司目錄裡的明確行為者，憑證限定任務範圍且不留在日誌中。它整合 Teams、Outlook、OneDrive、SharePoint，能跨時區排會、產生會前資料、自動保留行事曆時段、提前發現卡關的決策。Scout 建立在 2025 年 11 月出現的開源專案 OpenClaw 之上；敏感操作可要求人工簽核，並強制套用 Purview 的敏感標籤與資料外洩防護。目前僅對特定客戶私人預覽。

代號「M-dash」：百名代理人的資安蜂群

100+ agents hunting exploitable bugs in code

  • A multi-model agentic security system deploying 100+ agents to search for exploitable bugs.
  • Agents reason about data flows, business logic, exploit chains, and context-aware fixes inside the developer portal.
  • The point: a swarm of specialized agents can review code from angles a normal static scanner might miss.
  • (The name is a joke — AI-generated text is famously full of em dashes.)
繁中摘要
開發者端的驚喜是代號 M-dash 的多模型代理式資安系統（名字自嘲 AI 文章充滿破折號）。它會派出超過一百個代理人，從資料流、商業邏輯、漏洞利用鏈等不同角度搜尋程式中可被利用的弱點，並提出符合脈絡的修補建議——目標是抓出傳統靜態掃描器漏掉的問題。這顯示微軟的代理人戰略不限於辦公室工作，也延伸到軟體安全。

Majorana 2 量子晶片：宣稱可靠度提升 1000 倍

Topological qubits, 20-second lifetimes — and real scientific controversy

  • Next-gen topological quantum chip, developed with help from Microsoft Discovery's agentic AI.
  • Claims: 1,000× more reliable than the previous generation; mean qubit lifetime 20 seconds (up to 1 minute) — vs. microseconds/milliseconds in many approaches.
  • Analogy: like a phone battery going from one day to nearly 3 years per charge.
  • Only 12 qubits today (millions needed); Microsoft targets a commercially valuable quantum computer by 2029.
  • Material change: Majorana 1 used aluminum; Majorana 2 uses lead, which shields fragile qubits from cosmic disturbances.
  • Caveats: Microsoft retracted a 2018 Nature paper on Majorana evidence; the new research is not yet peer-reviewed; physicists are asking for more data.
繁中摘要
Majorana 2 是微軟新一代拓撲量子晶片，宣稱可靠度比前代提升一千倍：量子位元平均壽命 20 秒、最長 1 分鐘——多數方案還停在微秒或毫秒等級，微軟比喻像手機電池從撐一天變成撐近三年。目前只有 12 個量子位元（實用機需要數百萬個），但微軟設定 2029 年做出有商業價值的量子電腦。材料上從鋁改用鉛來屏蔽宇宙射線干擾。但要小心：微軟 2018 年那篇宣稱發現馬約拉納粒子證據的 Nature 論文曾被撤稿，這次的新研究也尚未經同儕審查，物理學界仍持保留態度。

Microsoft Discovery：用 AI 代理人做前沿研發

Teams of agents for frontier R&D — now generally available

  • Lets companies use teams of AI agents to search, research, generate hypotheses, optimize experiments, and validate ideas — with humans in control.
  • Microsoft's quantum team uses it to connect ~two decades of data across teams, formats, and systems.
  • Creating a topological quantum state means tuning hundreds of parameters; manual measurement took weeks — Discovery's agent cut the cycle by orders of magnitude.
  • One agent even found an uncalibrated temperature sensor hidden in fabrication data.
繁中摘要
Microsoft Discovery 平台正式開放，讓企業用「AI 代理人團隊」做前沿研發：搜尋、推理、提出假設、優化實驗、驗證構想，人類專家保持掌控。微軟自家量子團隊就是用它串起近二十年散落在不同團隊與格式的資料。打造拓撲量子態需要調整數百個參數，人工量測動輒數週，Discovery 的代理人把週期縮短了好幾個數量級，甚至從製程資料中揪出一個沒校準的溫度感測器。這是「AI 加速科學」的具體案例。

市場大局：投資人、夥伴、通路商，也是對手

Microsoft vs. the companies it funded

  • OpenAI and Anthropic are both moving toward massive IPOs — and Microsoft is tied to both.
  • Microsoft committed $13 billion to OpenAI, invested up to $5 billion in Anthropic, and sells both companies' models on Azure.
  • It is now simultaneously their investor, partner, distributor, infrastructure provider — and direct competitor.
  • The open question: how fast can Microsoft turn this into everyday products, and how much pressure does it put on OpenAI, Anthropic, and Google?
繁中摘要
這一切發生在微妙的時間點：OpenAI 與 Anthropic 都朝大型 IPO 邁進，而微軟對 OpenAI 投入 130 億美元、對 Anthropic 投資最高 50 億美元，並透過 Azure 銷售兩家的模型。如今微軟同時是它們的投資人、夥伴、通路商、基礎設施供應商——也是直接競爭者。Build 2026 因此不只是開發者大會，而是微軟對整個 AI 堆疊（模型、代理人、開發工具、企業資料、研究平台到量子硬體）的控制權宣示。接下來要看的，是這些東西多快變成大家每天用的產品。

📖 Glossary 重要詞彙表

frontier model前沿模型
當前能力最頂尖的 AI 模型；文中納德拉呼籲企業從「消費」前沿模型轉為「參與」前沿。
reasoning model推理模型
會先進行多步思考再作答的模型，適合處理複雜問題；MAI Thinking 1 即屬此類。
distillation（模型）蒸餾
用大模型的輸出來訓練小模型的技術。微軟強調 MAI Thinking 1「無蒸餾」，以避開法律與依賴風險。
active parameters活躍參數
推論時實際被啟用的參數數量（常見於 MoE 架構）；MAI Thinking 1 為 350 億活躍參數。
context window上下文視窗
模型一次能處理的文字長度，以 token 計；文中出現 256K 與 128K 兩種說法。
blind evaluation盲測評估
評審不知道答案來自哪個模型的比較測試，可減少品牌偏見；由獨立機構 Surge 執行。
SWE-Bench Pro軟體工程基準測試
以真實軟體工程任務評估模型寫程式能力的 benchmark。
cost efficiency成本效率
同樣品質下花費更少；微軟宣稱比 GPT-5.5 約有十倍優勢（依公開定價推算）。
intelligence layer智慧層
介於模型與應用之間、提供組織脈絡與資料連結的中介層，即 Microsoft IQ 的定位。
ontology本體論／語意架構
替資料定義概念與關係的「意義層」；Fabric IQ 替結構化商業資料提供類似功能。
grounding接地／資訊錨定
讓 AI 的回答建立在真實資料（公司內部資料或即時網路）上，以減少幻覺（hallucination）。
MCP (Model Context Protocol)模型上下文協定
代理人連接外部工具與資料來源的開放標準；Web IQ 原生支援 MCP。
autopilot agent常駐自動代理人
微軟提出的新類別：在背景持續運作、有自己身分、能在授權範圍內代表使用者行動的代理人（如 Scout）。
Entra identityEntra 身分
微軟的身分與存取管理系統；Scout 的每個動作都掛在可追溯的受治理身分之下。
DLP (Data Loss Prevention)資料外洩防護
防止敏感資料被不當傳送或寫出的安全政策；Scout 行動前會強制檢查。
exploit chain漏洞利用鏈
把多個弱點串接成完整攻擊路徑；M-dash 的代理人會推理這類攻擊鏈。
static scanner靜態掃描器
不執行程式、僅分析原始碼找漏洞的傳統工具；代理人蜂群被定位為其升級版。
qubit量子位元
量子電腦的基本運算單位，極為脆弱，溫度或震動的微小變化就會破壞其量子態。
topological qubit拓撲量子位元
微軟採用的量子位元路線，理論上更抗干擾，但科學上仍有爭議。
Majorana quasiparticle馬約拉納準粒子
1930 年代由義大利物理學家 Ettore Majorana 提出的理論粒子，是微軟量子路線的物理基礎；2018 年相關 Nature 論文曾遭撤稿。
peer review同儕審查
研究發表前由同領域專家審核的程序；Majorana 2 的研究尚未通過此關卡。
IPO (Initial Public Offering)首次公開募股
公司首次在股票市場公開上市；OpenAI 與 Anthropic 均傳出正朝大型 IPO 邁進。
general availability (GA)正式開放
產品脫離測試階段、對所有客戶開放使用；Microsoft IQ 與 Discovery 均已 GA。
private preview私人預覽
僅限受邀客戶試用的早期階段；MAI 模型與 Scout 目前多處於此階段。
