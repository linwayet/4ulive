第一篇 · 觀念地基

什麼是 AI 代理人？

⏱ 約 10 分鐘

這幾年我們最熟悉的 AI，是「你問一句、它答一句」的聊天機器人。但 2026 年大家掛在嘴邊的「AI 代理人（AI agent）」，已經是完全不同的東西。要分清楚，先看一條從被動到主動的光譜。

三層辨析：聊天機器人 → 副駕 → 代理人

  • 聊天機器人（Chatbot）：只會「生成文字」。你問問題，它回答，僅此而已。
  • 副駕（Copilot）：在你工作時「從旁輔助」，例如在編輯器裡建議下一行程式，但方向盤還在你手上。
  • 代理人（Agent）：你給它一個「目標」，它會自己規劃步驟、呼叫工具、觀察結果、發現不對就調整，循環執行直到任務完成。

用一句話總結業界 2026 年的共識：代理人不只是會把話說得漂亮，而是會設定目標、呼叫真實工具（API、檔案、瀏覽器、程式碼）、觀察發生了什麼、然後調整，一圈一圈循環到把事情做完。判斷一個產品是不是「真代理人」，關鍵不在它聽起來多聰明，而在它會不會在一個迴圈裡採取行動。

代理人、代理式系統、多代理人

還有三個常被混用的詞，這裡一次釐清：

  • AI 代理人（AI agent）是「名詞」：一個會自己完成單一明確任務的軟體系統。
  • 代理式（agentic）是「形容詞」：描述一個系統「能多自主地行動」。自主性是程度問題，是一條光譜，不是有或沒有。
  • 多代理人系統（multi-agent）：把很多各司其職的代理人組成一個團隊，由「協調」機制統籌，分頭完成一個大目標——這正是 2026 年成長最快的形態。
關鍵心法：分辨是不是代理人，問三句話就好——它有「目標」嗎？它會自己「呼叫工具」採取行動嗎？它會「循環修正」直到完成嗎？三個都是「是」，才是真正的代理人。
生活比喻 聊天機器人像「問路的路人」——你問，他指個方向。副駕像「副駕駛座的朋友」——幫你看地圖、提醒你轉彎，但你開車。代理人則像「專業司機兼跑腿」——你只說「幫我把這份合約送到對方公司並取回簽名版」，剩下的路線、停車、應對，他全部自己搞定，遇到塞車還會改道。
English Summary

An AI agent is not a chatbot or a copilot. A chatbot only generates text; a copilot assists while you stay in control; an agent takes a goal, plans the steps, calls real tools (APIs, files, browsers, code), watches the result, and loops until the task is done.

"AI agent" is the noun (a software system), while "agentic" is the adjective describing how autonomously it acts — autonomy is a spectrum, not a yes-or-no. A multi-agent system links many specialized agents under one orchestration layer, and it is the fastest-growing form in 2026. The test for a real agent: Does it have a goal, call tools to act, and loop to correct itself until finished?

代理人的四大組成（黃仁勳框架）

⏱ 約 10 分鐘

2026 年 6 月 1 日，黃仁勳在台北 Computex 主題演講上說，整場演講「最重要的一張投影片」就是：未來十年的運算型態，是代理人 + 協調外殼，協調著大型語言模型。他斷言，每一家公司都會變成「代理人公司」，內部都會跑代理人，也都需要一套自己的「代理人作業系統」。那麼，要打造一個代理人，到底需要什麼？他給了一個很好記的四件套。

打造代理人的四樣東西

  • ① 模型（Model）：也就是大型語言模型，是代理人的「大腦」。越聰明、越便宜、越快越好。
  • ② 協調外殼（Orchestration Shell）：負責「協調整件事」的指揮中心——決定先做什麼、呼叫哪個工具、何時交棒。
  • ③ 工具與技能（Tools & Skills）：模型想動手，就需要工具；每個工具會附帶一份「技能說明書」，告訴模型怎麼用。
  • ④ 執行環境（Runtime）：把以上一切凝聚起來、實際安全運行的「作業系統」。

NVIDIA 的答案：NeMo 工具包與 Open Shell

把這四樣東西合起來，就是 NVIDIA 的企業 AI 代理人工具包，名叫 NeMo。它附帶可修改的世界級開放模型，也能直接跑別人家的代理人（例如 Claude Code、Codex）。這些代理人跑在一個叫 Open Shell 的開源協調外殼裡（對外框架名為 NemoClaw），在企業內部高度安全——它會用安全政策約束代理人、保護隱私、並管好代理人的「身分與權限」。Open Shell 能跑在任何雲端、地端，甚至裝置上。

為什麼「外殼」這麼重要？因為代理人會真的去動你的檔案、寄你的信、刷你的卡。沒有一層協調外殼幫它「踩煞車、查權限、留紀錄」，放出去亂跑是很危險的。外殼＝代理人的保鑣兼交通警察。
生活比喻 把代理人想成一間「智慧廚房」：模型是主廚的大腦，工具與技能是鍋鏟與食譜，執行環境是整間廚房，而協調外殼就是那位外場經理——決定出菜順序、控管誰能進廚房、確保食安。少了經理，再強的主廚也會手忙腳亂。
English Summary

At Computex 2026 (June 1), Jensen Huang called it his most important slide: the computing model of the next decade is agents plus an orchestration shell, orchestrating large language models. Every company, he said, will become an "agent company" needing its own agent operating system.

Building an agent takes four things: a model (the brain — smarter, cheaper, faster), an orchestration shell (the coordinator), tools and skills (with instruction manuals), and a runtime (the OS that holds it together). NVIDIA packages these as the NeMo toolkit, running agents — including Claude Code or Codex — inside an open, secure orchestration shell called Open Shell (framework name NemoClaw) that enforces security policy, protects privacy, and manages each agent's identity and permissions across cloud, on-premises, or device.

第一篇 · 觀念地基

代理人怎麼長出來的？發展史

⏱ 約 10 分鐘

代理人不是 2026 年突然冒出來的，它是好幾項技術慢慢匯流的結果。我們用幾個關鍵節點，把這條路走一遍。

關鍵時間軸

  • 1966 ELIZA：最早的對話程式，只會做樣板比對，談不上理解。
  • 2023 函式呼叫（function calling）：這一年是分水嶺。LLM 第一次能用結構化、可預測的格式去「呼叫工具」，用 JSON 傳參數、與外部系統互動——代理人有了「手」。
  • 2024 年底 MCP：Anthropic 推出開源的「模型情境協定」，讓代理人與外部工具、資料源的串接有了標準介面，等於替整個生態打造了「萬用插座」。
  • 2024–2025 推理模型：o 系列、Claude Opus 系列、Kimi 等模型學會「先想再答」——把難題拆成小步、測試假設、自我糾錯，這正是代理人需要的規劃能力。
  • 2026 代理人時代：模型能連續執行超過半小時以上的多步驟任務，從佈建雲端基礎設施到修掉複雜的程式錯誤，端到端完成。

讓代理人彼此對話的「協定三兄弟」

代理人要協作，需要共通語言。除了 Anthropic 的 MCP（代理人對工具），還有 Google 的 A2A（Agent-to-Agent，代理人對代理人）與 IBM 的 ACP。後兩者後來在 Linux 基金會下整合，讓代理人生態真正繁榮起來。

市場有多大？AI 代理人市場 2024–2025 年約 54–78 億美元，多家機構預估到 2030–2034 年將衝上 500 至 2360 億美元，年複合成長率高達約 45–46%。這是少見的「整個十年都在陡升」的曲線。
生活比喻 這條路就像「機器人學會做事」的三步：先有嘴巴（會說話的 LLM）→ 再裝上手（函式呼叫，能拿工具）→ 最後接上標準插座（MCP，任何工具都能插）。三者齊備，它才從「會聊天的玩具」變成「能幹活的同事」。
English Summary

Agents emerged from converging technologies. From ELIZA's pattern-matching in 1966, the turning point came in 2023 with function calling, which let LLMs call tools in a structured, predictable way — giving them "hands." In late 2024, Anthropic's open Model Context Protocol (MCP) standardized how agents connect to external tools and data, like a universal adapter.

Reasoning models (the o-series, Claude Opus, Kimi) in 2024–2025 added "think-before-answering" planning, and by 2026 agents run multi-step tasks for 30+ minutes end to end. Communication protocols — MCP (agent-to-tool), plus A2A and ACP (agent-to-agent) — let agents collaborate. The market, roughly $5.4–7.8B in 2024–25, is projected to reach $50–236B by 2030–2034 at a 45–46% CAGR.

硬體需求（上）：資料中心為何吃電吃晶片

⏱ 約 10 分鐘

為什麼代理人比聊天機器人「燒」更多算力？因為聊天只回一句話，代理人卻要規劃、呼叫工具、讀大量資料、反覆嘗試——這些動作通通發生在「推論（inference）」階段，也就是模型實際幹活、吐出 token 的時候。

訓練 vs 推論，以及「測試時運算」

  • 訓練（training）：把模型「教會」，是一次性的大工程。
  • 推論（inference）：模型「上工回答」，每天不斷發生。代理人時代的算力大頭從訓練轉向了推論。
  • 測試時運算（test-time scaling）：讓模型在回答時「多想一下」、多花算力產生更多 token，答案就更好——但這也讓推論成本暴增。

關鍵難點在「長上下文」。代理人推理時，往往要一口氣處理數十萬個輸入 token，才能撐起多步驟的工作流程與長記憶。資料中心因此被重新定義成「AI 工廠」——不再是偶爾回應人類請求，而是全天候、不停把電力、晶片與資料轉換成智慧的生產線。

Vera Rubin：為代理人而生的平台

這正是 NVIDIA 推出 Vera Rubin 平台的原因。它的 NVL72 機櫃整合多款晶片，包含全新的 Vera CPU（演講中強調「專為代理人設計」）與 Rubin GPU，宣稱相較前一代，推論吞吐量達 10 倍、每 token 成本降到十分之一。換句話說，代理人要能「便宜地一直想」，背後得有這種專門的硬體撐腰。

Tokenomics（代幣經濟學的另一義）：在 AI 圈，這個詞指的是「每個 token 要花多少電、多少錢、多少時間」。代理人會狂吐 token，所以誰能把「每 token 成本」壓到最低，誰就握有規模化代理人的鑰匙。
生活比喻 訓練像「考前苦讀」——辛苦但一次性；推論像「天天上班幹活」。聊天機器人是接電話的櫃台，講完就掛；代理人卻像跑專案的工程師，要查資料、開會、反覆改稿。後者當然更耗腦力（算力），所以需要一座專為「長時間連續動腦」打造的工廠。
English Summary

Agents burn far more compute than chatbots because planning, tool-calling, and retrying all happen during inference. The compute center of gravity has shifted from training (a one-time effort) to inference (everyday work), amplified by test-time scaling — letting a model "think harder" by spending more compute and tokens for better answers.

The hard part is long context: agentic reasoning may process hundreds of thousands of input tokens at once. Data centers are being redefined as always-on "AI factories." NVIDIA's Vera Rubin platform answers this, with a NVL72 rack integrating the new Vera CPU (built for agents) and Rubin GPU, claiming up to 10x inference throughput and one-tenth the cost per token versus the prior generation. Whoever drives "cost per token" lowest holds the key to scaling agents — the heart of "tokenomics."

硬體需求（下）：代理人走進你的電腦

⏱ 約 10 分鐘

代理人不一定要待在遙遠的雲端。2026 年的另一條主線，是讓代理人「跑在你自己的裝置上」——更私密、更即時、不必把資料送上雲。

本地端與邊緣代理人

  • RTX Spark 超級晶片：NVIDIA 與微軟合作，要把 PC 從「跑應用程式的機器」變成「能運行私人本地代理人的裝置」。它用 Grace Blackwell 架構配 128GB 統一記憶體，足以在本地跑到約 1050 億參數（4-bit 量化）的模型。今年秋季由 ASUS、Dell、HP、Lenovo、微軟 Surface、MSI 等推出。
  • DGX Station：桌上型的「個人 AI 超級電腦」，搭 HBM3e 記憶體，連 Windows 都能跑，目標是在本地驅動到兆級參數模型。
  • 開放模型 Nemotron 3 Ultra：5500 億參數、專為長時間運行的代理人設計，宣稱推論快 5 倍、成本低 3 成，而且連模型、訓練腳本與資料全部開放。它是全球第一款結合「狀態空間模型 + 專家混合」的混合架構模型。

壓軸實例：Cadence 晶片設計超級代理人

黃仁勳最愛的案例，是用代理人來「設計晶片」。NVIDIA 與 Cadence 合作打造的設計驗證代理人，由開放模型 Nemotron 驅動、由 Open Shell 保護，再調用一群專家子代理人（負責生成設計語言、建立測試、跑回歸測試、除錯）。它一口氣跑數百次模擬、做形式化驗證，揪出程式瑕疵並修好——讓原本要好幾週的驗證週期，縮短到幾小時，快了四十倍以上。NVIDIA 說未來要雇用「數十萬個」這種超級代理人，和數千名人類工程師一起工作。

本地端為什麼吸引人？三個字：隱私、即時、自主。敏感資料不出門、回應沒有網路延遲、斷網也能用。Vera Rubin 等資料中心硬體甚至內建「機密運算」，在晶片層級加密，連多租戶之間都彼此隔離。
生活比喻 雲端代理人像「外送大廚房」——火力強但要等運送、要把你的訂單交出去；本地端代理人像「自家廚房」——也許爐子小一點，但食材不出門、想煮就煮、半夜停電還能點蠟燭炒個蛋。2026 年的趨勢，是兩種廚房並存，看任務挑工具。
English Summary

Agents don't have to live in distant clouds. A second 2026 storyline is running them on your own device — more private, lower latency, no need to ship data out. NVIDIA's RTX Spark superchip (with Microsoft) turns a Windows PC into a host for private local agents, using Grace Blackwell with 128GB unified memory to run models up to ~105B parameters (4-bit) locally; the DGX Station scales this toward trillion-parameter models on the desktop.

The open Nemotron 3 Ultra (550B parameters, ~5x faster inference, ~30% lower cost) is fully open — model, scripts, and data — and is the first hybrid of state-space and mixture-of-experts architectures. The flagship example: NVIDIA and Cadence's chip-design verification super agent, powered by Nemotron and protected by Open Shell, runs hundreds of simulations to cut verification cycles from weeks to hours — over 40x faster.

第二篇 · 商用實戰 70 例

客服與零售電商

⏱ 約 10 分鐘 · 10 個案例

客服是企業導入代理人最快、成效最容易衡量的起點；零售與電商則把代理人推向「消費者直接互動」的最前線——甚至改變了我們「搜尋→購買」的習慣。

🛒Klarna（瑞典金融科技）
客服 AI 代理人處理大量例行詢問，公司宣稱相當於 853 名員工的工作量。省下約 6,000 萬美元
⚡Walmart「Sparky」
App 內的購物代理人，逐步加入代理式商務功能：自動重新下單、無縫客服、更省力的購物體驗。
📦Amazon「Rufus」
面向消費者的購物助理代理人，協助比較、推薦與決策。
🎯Target × Gemini / Copilot
2026 年初把商品上架到 Google Gemini、微軟 Copilot 等外部 AI 代理人平台，搶攻「代理式商務」。
🧶Etsy
將手作商品接上 ChatGPT 等代理人平台，讓 AI 助理能直接幫消費者選購、下單。
🏪Shopify Agentic Storefronts
讓任何 Shopify 商家「一次設定」就能被 ChatGPT、Perplexity、Copilot 等代理人發現與成交。
💬Decagon
專注客服自動化的代理人平台，2026 年估值約 45 億美元，已有具名企業上線部署。
🤖Sierra
由前 Salesforce 共同執行長創辦的客服代理人平台，估值約 158 億美元，產品成熟度高。
🗣️Avaamo / Hyro
對話式代理人平台，廣泛用於客服與預約，能跨管道（語音、簡訊、網頁）自動應答。
✈️某航空公司（Deloitte 案例）
用代理人協助旅客自助完成最常見的交易，如改票、行李改道，讓人力專注於複雜個案。
English Summary

Customer service is the fastest, easiest-to-measure entry point for enterprise agents, while retail pushes them to the consumer front line — reshaping the "search then buy" habit into agentic commerce.

Flagship cases: Klarna's support agent did the work of 853 employees (~$60M saved); Walmart's Sparky and Amazon's Rufus are consumer shopping agents; Target, Etsy, and Shopify make products discoverable and buyable inside ChatGPT, Gemini, and Copilot. Specialist platforms Decagon (~$4.5B) and Sierra (~$15.8B) lead pure customer-service deployments.

金融、銀行與保險

每天有 450 個以上的 AI 應用上線運行：30 秒生成投行簡報、起草併購備忘錄、自動交易結算、即時偵測詐欺。

金融科技客服代理人，是最常被引用的 ROI 標竿之一。
🔗Mastercard
推動 UCP 代理式商務標準，讓 AI 代理人能安全地代消費者完成結帳與交易。

誠實面：代理人還做不到什麼

「代理人」是 2026 年最被濫用的詞，行銷話術與真正能交付的東西落差很大。一個務實的判準：需要連續執行超過數小時不被人類審查、或在高度監管且有稽核要求的產業裡運行的代理式工作流程，目前大多還做不到。聽到廠商說「全自動、不用管」，請保持懷疑。

治理：放出去之前要繫好安全帶

  • 權限與身分：代理人能動你的檔案、寄你的信、刷你的卡，務必最小權限、可隨時收回。
  • 隱私：敏感資料盡量留在本地或機密運算環境，別輕易送上不明雲端。
  • 可稽核：留下「誰、何時、做了什麼」的完整紀錄——這正是回合 2 那層「協調外殼」的價值。
  • 人類把關（human-in-the-loop）：高風險動作（付款、刪除、對外發送）一定要設人類確認關卡。

人機協作，而非取代

黃仁勳在 Computex 直接回應「代理人會不會搶工作」：他說恰恰相反，代理人需求反而推升了軟體工程師的需求。代理人將為合作夥伴創造史上最大的機會。務實的看法是：代理人擅長分擔「重複但需要判斷」的雜務，讓人類把時間花在判斷、創意與關係經營上。

給自學者的下一步：① 先選「一個你每天都做的小任務」交給一個代理人試水溫（例如 Perplexity 做查證、Claude Code 做小腳本）。② 學會一個協調概念（MCP／工具呼叫）。③ 讀懂治理三原則（最小權限、可稽核、人類把關）。④ 用「原子習慣」的節奏，一天一個小實驗，三個月後你會驚訝自己走多遠。
生活比喻 代理人就像剛到職、很有潛力的實習生：交給它明確、低風險的任務會很驚艷；但你不會第一天就給它公司印章和金庫鑰匙。聰明的主管會「逐步授權、保留複核」——這也是 2026 年用代理人的黃金守則。
English Summary

"Agent" is 2026's most overused word; marketing outruns delivery. A practical test: workflows that must run unsupervised for many hours, or operate in heavily regulated, audit-bound industries, mostly don't work yet — be skeptical of "fully autonomous, hands-off" claims.

Govern before you deploy: least-privilege identity, privacy (keep sensitive data local or in confidential computing), auditability, and human-in-the-loop checkpoints for risky actions. At Computex, Huang argued agents raise demand for software engineers rather than replacing them — they augment humans. For self-learners: hand one small daily task to one agent, learn one orchestration concept (MCP/tool-calling), internalize the three governance rules, and run one small experiment a day, Atomic-Habits style.

Glossary 詞彙表

本課程關鍵術語的中英對照與白話解釋（含黃仁勳演講提到的核心字）。

AI 代理人　AI agent
會設定目標、呼叫工具、循環執行直到完成任務的軟體系統。是「名詞」。
代理式（的）　agentic
形容一個系統能多自主地行動。是「形容詞」，自主性是程度光譜。
多代理人系統　multi-agent system
由多個各司其職的代理人組成、經協調統籌的團隊，2026 年成長最快的形態。
大型語言模型　large language model (LLM)
代理人的「大腦」，理解與生成語言、規劃步驟的核心模型。
協調外殼　orchestration shell
統籌代理人行動的指揮中心，負責踩煞車、查權限、留紀錄。如 NVIDIA 的 Open Shell。
工具呼叫／函式呼叫　tool calling / function calling
LLM 用結構化格式呼叫外部工具的能力，2023 年的關鍵突破，代理人的「手」。
模型情境協定　Model Context Protocol (MCP)
Anthropic 2024 年底推出的開源標準，讓代理人與外部工具/資料源串接，像「萬用插座」。
代理人對代理人協定　A2A / ACP
讓不同代理人彼此溝通協作的協定（Google A2A、IBM ACP），後於 Linux 基金會整合。
檢索增強生成　RAG
讓模型回答前先「查資料」，把外部知識帶進答案，減少憑空亂編。
推理模型　reasoning model
會「先想再答」、把難題拆步驟、自我糾錯的模型，如 o 系列、Claude Opus。
推論　inference
模型「上工回答」的階段（相對於一次性的訓練）。代理人時代算力大頭在此。
訓練　training
把模型「教會」的一次性大工程。
測試時運算　test-time scaling
讓模型在回答時多花算力、多想一下，答案更好但成本更高。
代幣／詞元　token
模型處理文字的最小單位。代理人會大量產生 token。
代幣經濟學　tokenomics
在 AI 語境指「每個 token 要花多少電、錢、時間」，是規模化代理人的成本關鍵。
長上下文　long context
模型一次能處理的資訊量。代理人多步驟推理常需數十萬 token 的長上下文。
企業　enterprise
指大型公司組織。「企業級」代理人強調安全、權限與可稽核。
開放模型　open model
把模型權重公開、可下載修改的模型，如 Nemotron 3 Ultra。
開源　open source
把程式設計圖免費公開，任何人都能看、改、用。像公開的食譜。
隱私　privacy
保護個人與機構的敏感資料不外洩，是本地端代理人的核心賣點。
混合架構　hybrid architecture
把兩種設計的優點結合，如 Nemotron 結合狀態空間模型與專家混合，又快又省。像油電混合車。
專家混合　mixture of experts (MoE)
模型內含多個「專家」子網路，每次只啟動需要的部分，省算力。
狀態空間模型　state space model (SSM)
一種處理長序列更高效的模型架構，常與其他架構混合使用。
形式化驗證　formal verification
用數學方法嚴格證明設計（如晶片）沒有特定錯誤，比抽測更徹底。
除錯　debug
找出並修掉程式裡的錯誤（俗稱臭蟲）。在晶片設計裡一個小臭蟲可能延誤數月。
機密運算　confidential computing
在晶片層級加密資料、隔離多租戶的安全技術，連運算過程都受保護。
執行環境　runtime
代理人實際安全運行的作業系統層，把模型、工具、外殼凝聚起來。
提示注入　prompt injection
攻擊者把惡意指令藏在資料裡，誘騙代理人執行的資安風險。
人類把關　human-in-the-loop
在高風險動作前設置人類確認關卡，是安全使用代理人的黃金守則。
SWE-bench
評測 AI 解決真實軟體工程問題能力的基準測試，常用來比較程式開發代理人。
資安維運中心　SOC
企業偵測與回應資安威脅的團隊，2026 年大量導入代理人協助分流與調查。
電子病歷　EHR
醫院的數位病歷系統，醫療代理人多需與之串接（常用 FHIR/HL7 標準）。
